📱 考研单词卡 · 手机安装说明

两种装法，任选其一。推荐方案 A（真 APK）：更快、更稳、彻底离线。

方案 A · 推荐 安装 APK（真 App）

  1. 把 考研单词卡-v1.0.0.apk 传到手机（微信文件传输助手 / 数据线 / 网盘都行）
  2. 在手机「文件管理」里点开这个 apk
  3. 提示「未知来源应用」→ 按提示进入设置，允许「安装未知应用」，返回继续
  4. 装好后桌面出现蓝色「考研单词」图标，点开即全屏运行
这个版本的特点
· 完全不联网——没有申请网络权限，飞机上、没信号都能用
· 385 个单词的 发音音频全部内置（18MB），点开就能听，不用等下载
· 学习进度存在手机本地，卸载会清空
提示：如果安装时系统提示「应用未经安全检测」，选择「继续安装」即可。这个 apk 是我在你自己的电脑上用官方 Android 工具链构建并签名的，没有上传到任何第三方商店。

方案 B 装到桌面（PWA，无需下载文件）

  1. 手机用 Chrome 打开：
    https://clementbarnes.github.io/kaoyan-study/单词卡.html
  2. 点浏览器右上角 「⋮」 菜单
  3. 选 「安装应用」 或 「添加到主屏幕」
  4. 确认后桌面出现「考研单词」图标，点开全屏无地址栏
单词卡页面顶部会直接弹一条「一键安装」横幅，点一下就调起系统安装框，不用自己找菜单。
这个版本需要联网加载页面，但音频可以点「缓存本批音频」存到本地，之后也能离线听。

📊 两种方案怎么选

对比项方案 A（APK）方案 B（PWA）
首次打开速度秒开（全本地）要联网加载
断网使用完全可用页面需已缓存
发音音频全部内置，零等待需先缓存
更新内容重新装新版本刷新自动更新
占用空间约 19MB约 1MB 起（可缓存）
建议：先装 APK 天天用，PWA 版本留作备用（内容更新更及时）。两者进度不互通，各存各的。

❓ 常见问题

Q：装上后发音没声音？
检查手机媒体音量是否静音，不要用「勿扰/静音」模式。

Q：能多设备同步进度吗？
APK 版进度存本地。目前进度同步靠资料库（云端表格）手动录入，跨设备以云端为准。

Q：以后词库更新了怎么办？
告诉我，我重新打包一个新版 apk 给你，直接覆盖安装即可，进度会保留。
