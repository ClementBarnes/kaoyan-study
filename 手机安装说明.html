📱 考研单词卡 · vivo 安装说明

适配 OriginOS（vivo / iQOO）。按顺序做，约 1 分钟。

第一步 下载 APK

1
手机点这个链接直接下 ⬇️ 下载考研单词卡 v1.1.3（19MB）
下不动就把这串地址贴到浏览器：
clementbarnes.github.io/kaoyan-study/download/kaoyan-words-v1.1.3.apk
2
或用微信传（没法下载时） 电脑上把 考研单词卡-v1.1.3.apk 发到「文件传输助手」→ 手机微信点开文件 → 右上角「⋯」→「保存到手机」→ 再用「文件管理」打开。
别在微信里直接点「安装」，微信内置安装器容易被 vivo 拦。先存到手机，用文件管理打开最稳。

关键 打开「允许安装未知应用」

不做这一步，安装会被直接拦下。两条路，任选：

路子 A（最省事）

  1. 点开 APK，vivo 弹「为了安全，禁止安装此来源的应用」
  2. 点弹窗里的 「设置」（不是「取消」）
  3. 打开 「允许安装未知应用」 开关 → 返回 → 重新点 APK

路子 B（弹窗里没找到设置）

  1. 设置 → 应用与权限 → 权限管理
  2. 找 「安装未知应用」（有的版本在右上角菜单里）
  3. 在列表里找到你用来打开 APK 的应用（文件管理 / 浏览器 / 微信）
  4. 把它的开关打开
找不到菜单？在「设置」页顶部搜索框直接搜 安装未知应用 或 未知来源，vivo 会直接跳到开关。OriginOS 各版本菜单位置不一样，搜索最快。

容易卡住 纯净模式 / i管家 拦截

权限开了还是装不上，或提示「已开启纯净模式，无法安装」，按下面处理：

  1. 设置 → 安全（或「安全与隐私」）→ 更多安全设置 → 纯净模式 → 关闭
  2. 安装时若弹 i管家 的「安全检测／风险提示」，选 「继续安装」 或 「仍要安装」
  3. 若提示「该应用未上架应用商店」—— 正常，这是你自己打的包，选继续即可
安全性可以自己验：这个 APK 在你自己的电脑上用官方 Android 工具链构建，没有申请任何权限（连联网权限都没有）。装完去「设置 → 应用与权限 → 权限管理 → 考研单词」，权限列表应该是空的。

装好之后 建议开两个开关

vivo 后台管理比较激进，这两个开关能防止学习进度被意外清理：

  1. 设置 → 电池 → 后台耗电管理 → 找「考研单词」→ 选 「允许后台高耗电」
  2. i管家 → 应用管理 → 自启动 → 找「考研单词」→ 打开
不做也能用。进度存在应用自己的数据目录里，普通清理不会动；只有「清除数据 / 卸载」才清空。

重要：如果之前装过 v1.0.0，必须先卸载再装 v1.1.3 —— 两次签名密钥不同，系统不允许覆盖。卸载会清空进度，但反正还没开始学。
