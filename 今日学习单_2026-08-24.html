词根 ① -mob / -mot / -mov = = 动（move）

钩子：mob → 联想「mobile 移动的」「motor 马达（驱动力）」，核心是"动"。

mobile/ˈməʊbaɪl/adj. 移动的，可动的（mob 动 + -ile 能…的 → 能动的）例：Mobile phones are everywhere. 手机无处不在。
motion/ˈməʊʃn/n. 运动，动议（mot 动 + -ion 名词 → 运动）例：The car is in motion. 汽车在运动中。
motivate/ˈməʊtɪveɪt/v. 激励，激发（mot 动 + -iv- + -ate 使 → 使…动起来 → 激励）例：Praise can motivate students. 表扬能激励学生。
promote/prəˈməʊt/v. 促进，晋升（pro- 向前 + mote 动 → 向前推动 → 促进）例：The policy promotes growth. 该政策促进增长。
remove/rɪˈmuːv/v. 移开，去除（re- 离开 + move 动 → 移走 → 去除）例：Remove the obstacles. 清除障碍。
词根 ② -sol = = 单独 / 唯一（alone）

钩子：sol → 联想「solo 独唱」「solitary 独居」，核心是"单独/唯一"。

sole/səʊl/adj. 唯一的，单独的（sol 单独 + -e → 唯一的）例：the sole survivor 唯一的幸存者
solo/ˈsəʊləʊ/n./adj. 独奏，单独的（sol 单独 + -o 音乐术语 → 独奏）例：a solo performance 独奏表演
isolate/ˈaɪsəleɪt/v. 隔离，孤立（isol 单独 + -ate 使 → 使孤立）例：isolate the patient 隔离病人
desolate/ˈdesələt/adj. 荒凉的，孤独的（de- 加强/剥夺 + sol 单独 + -ate → 无人烟的 → 荒凉）例：a desolate island 荒岛
solitude/ˈsɒlɪtjuːd/n. 独处，孤独（sol 单独 + -itude 名词 → 孤独）例：enjoy solitude 享受独处
词根 ③ -lev = = 轻 / 举（light / raise）

钩子：lev → 联想「elevator 电梯（举起）」「alleviate 减轻」，核心是"举/轻"。

elevate/ˈelɪveɪt/v. 提升，抬高（e- 出/向上 + lev 举 + -ate → 举起 → 提升）例：elevate the standard 提高标准
lever/ˈliːvə/n. 杠杆（lev 举 + -er 工具 → 杠杆）例：pull the lever 拉杠杆
relieve/rɪˈliːv/v. 减轻，缓解（re- 再 + liev 轻(=lev) + -e → 再减轻 → 缓解）例：relieve the pain 缓解疼痛
relevant/ˈreləvənt/adj. 相关的（re- 再 + lev 举 + -ant → 被举出/提及的 → 相关的）例：relevant information 相关信息
levy/ˈlevi/v./n. 征收（lev 举 + -y → 举起（征收）→ 征税）例：levy a tax 征税
词根 ④ -magn / -maj / -max = = 大（great / large）

钩子：magn → 联想「magnate 巨头（大人物）」「maximum 最大」，核心是"大"。

magnify/ˈmæɡnɪfaɪ/v. 放大，夸大（magn 大 + -ify 使 → 放大）例：magnify the image 放大图像
magnitude/ˈmæɡnɪtjuːd/n. 巨大，量级（magn 大 + -itude 名词 → 大小/量级）例：the magnitude of the problem 问题的严重性
magnificent/mæɡˈnɪfɪsnt/adj. 壮丽的（magn 大 + -ific 使 + -ent → 宏伟的）例：a magnificent view 壮丽的景色
major/ˈmeɪdʒə/adj. 主要的；n. 主修（maj 大 + -or → 主要的）例：a major problem 主要问题
maximum/ˈmæksɪməm/n./adj. 最大（值）（max 大 + -imum 最高级名词 → 最大值）例：the maximum speed 最大速度
