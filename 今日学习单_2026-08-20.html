第 10 批 20 词 · 4 组全新词根（对照总表零重复）：
• -cap / -cip 抓·取：capture 捕获 / capable 有能力的 / capacity 容量 / captive 俘虏 / occupy 占据
• -leg / -lig 选·绑·读：legal 合法的 / legend 传说 / college 学院 / eligible 符合条件的 / privilege 特权
• -mand / -mend 命令·托付：command 命令 / demand 要求 / recommend 推荐 / mandatory 强制的 / commander 指挥官
• -min / -minu 小：minute 微小的 / minimum 最小的 / minor 较小的 / minority 少数 / diminish 减少
记忆钩子：记一个根，串起一串词。比如 -cap=抓：capable=能抓住事→胜任；capacity=能抓住的容量→容量；occupy=抓牢→占据。-leg=选/法：college=被选中聚集之地→学院；eligible=被选出的→合格的；privilege=私人的法律→特权。-mand=命令：command=共同下令；demand=向下命令→强求；recommend=再共同托付→推荐。-min=小：minimum=最小的；minor=较小的；diminish=使变小→减少。
💡 第 10 批 20 词 + 前 9 批 188 词，活跃词根词汇已约 208 个。这四族（抓/选/命令/小）在完型、阅读、作文里都高频（如 capable、legal、recommend、minority 都是阅读常客，privilege、capacity 是作文加分词），优先滚熟。注意 occupy 和 capacity 拼写易混（都含 -cap-），可刻意对比记一次。

2. 长难句 12 · 30 min（非谓语动词，主干之外的第五种"装饰"）

第 8–11 讲覆盖了并列、定语、状语、名词性从句四种"挂在主干上的成分"。今天讲第五种高频装饰——非谓语动词：doing / done / to do 出现在名词或句子中间，不作谓语，而是当形容词或副词用，修饰前面的名词或整句。它最大的坑是：长得像谓语，其实不是，容易让你数错"有几个动作"。

Facing mounting pressure from investors, the CEO announced a plan to restructure the company, aiming to restore confidence.
生词预习：
• facing /ˈfeɪsɪŋ/ v. 面对（face 的现在分词，此处作状语）
• mounting /ˈmaʊntɪŋ/ adj. 不断增加的（mount 爬升 → -ing）
• investors /ɪnˈvestəz/ n. 投资者（invest + -or + 复数）
• restructure /ˌriːˈstrʌktʃə/ v. 重组（re- 再 + struct 建造 → 重建结构）
• restore /rɪˈstɔː/ v. 恢复（re- 再 + store 储存 → 复原）
• confidence /ˈkɒnfɪdəns/ n. 信心（con- 共同 + fid 信任 → 第04批 fid? 此处作认知，认识即可）
三步拆解：
  1. 先抓唯一谓语：整句真正的谓语动词只有 announced（CEO 宣布）。记住——一个主句只有一个谓语，其余带 -ing / -ed / to 的都"不是谓语"。
  2. 拆句首 doing 状语：Facing mounting pressure from investors（面对投资者日益增长的压力）是现在分词短语，修饰整个主句，相当于"因为/当…时"——这正是第 10 讲学的状语，只不过这次用分词表达。
  3. 拆名词后的修饰：to restructure the company（去重组公司）是不定式作 plan 的后置定语——"重组公司的计划"；aiming to restore confidence（旨在恢复信心）是现在分词作伴随状语，说明 announced 的目的/伴随。
💡 非谓语动词识别口诀："动词变了形，就不是谓语"——看到 doing / done / to do 别慌，先问三件事：①它是不是句子唯一谓语？（通常不是）②它修饰谁？（前面的名词，还是整句）③它表达什么关系？（时间/原因/目的/修饰）。把这几块"装饰"摘下来，主干 the CEO announced a plan 立刻干净。你能说出这句里几个非谓语动词、各修饰什么吗？（答案：facing 修饰主句；to restructure 修饰 plan；aiming 修饰 announced。共 3 个。）

维持练习 · 5 道基础题（自测，答案在末尾）：
  1. 某数增加 20% 后再减少 20%，最终结果是原数（相等 / 变小 / 变大）？
  2. 解方程：2(x − 3) = 3x + 1，求 x。
  3. 若 a : b = 2 : 3，且 a + b = 20，求 b 的值。
  4. 一个直角三角形两直角边为 3 和 4，斜边是多少？
  5. 一批零件，甲单独做需 6 小时，乙单独做需 3 小时，两人合作需几小时？
参考答案（先自己算，再对）：
① 变小（设原数 100：×1.2=120，×0.8=96 < 100）。
② x = −7（2x−6=3x+1 → −x=7 → x=−7）。
③ b = 12（a=2k,b=3k → 5k=20 → k=4 → b=12）。
④ 5（勾股：√(3²+4²)=5）。
⑤ 2 小时（效率和：1/6+1/3=1/2，故 1÷1/2=2）。全对说明基础手感在线；错哪题，把对应考点在《考研学习计划》数学部分标个星，周末集中刷。
✅ 数学轻维持不求"刷难题"，求"基础公式不遗忘"。今天 5 题、5 分钟就能过，数感就保住了。正式数学专题等工作日轮到时再做，不急。
