词根 ① -cap / -cip = = 抓 / 取（take / seize）

钩子：cap → 联想「capture 捕获（抓住）」「capital 首都（抓权之地）」，核心是“抓/取”。

capture/ˈkæptʃə/v. 捕获，占领（cap 抓 + -ture → 抓住）例：capture the moment 捕捉瞬间
capable/ˈkeɪpəbl/adj. 有能力的（cap 抓 + -able 能…的 → 能抓事 → 有能力的）例：a capable leader 能干的领导
capacity/kəˈpæsəti/n. 容量，能力（cap 抓 + -acity → 抓的量 → 容量）例：a large capacity 大容量
captive/ˈkæptɪv/adj. 被俘的；n. 俘虏（cap 抓 + -ive → 被抓的）例：hold someone captive 囚禁某人
occupy/ˈɒkjupaɪ/v. 占据，占用（oc- 朝向 + cup[y] 抓 → 抓住 → 占据）例：occupy the seat 占座
词根 ② -leg / -lig = = 选 / 绑 / 读（choose / bind / read）

钩子：leg → 联想「legal 合法的（绑定的规则）」「college 学院（选出来的一群）」，核心是“选/绑”。

legal/ˈliːɡl/adj. 合法的（leg 法/绑 + -al → 合法的）例：legal rights 合法权利
legend/ˈledʒənd/n. 传说，图例（leg 读 + -end → 被读诵的 → 传说）例：a famous legend 著名传说
college/ˈkɒlɪdʒ/n. 学院，大学（col- 共同 + leg 选 → 选在一起 → 学院）例：go to college 上大学
eligible/ˈelɪdʒəbl/adj. 有资格的（e- 向外 + lig 选 + -ible → 被选出的 → 合格的）例：eligible for the job 有资格任职
privilege/ˈprɪvəlɪdʒ/n. 特权（priv- 私 + leg 法 → 私法 → 特权）例：a special privilege 特殊特权
词根 ③ -mand / -mend = = 命令 / 托付（order / entrust）

钩子：mand → 联想「command 命令（交托指令）」，核心是“命令/托付”。

command/kəˈmɑːnd/v./n. 命令，指挥（com- 共同 + mand 托付 → 委命 → 指挥）例：command the army 指挥军队
demand/dɪˈmɑːnd/v./n. 要求，需求（de- 向下 + mand 命令 → 下命令 → 要求）例：meet the demand 满足需求
recommend/ˌrekəˈmend/v. 推荐，建议（re- 再 + com- + mend 托付 → 托付 → 推荐）例：I recommend this book. 我推荐这本书。
mandatory/ˈmændətəri/adj. 强制的，义务的（mand 命令 + -atory → 命令的 → 必须的）例：mandatory training 强制培训
commander/kəˈmɑːndə/n. 指挥官（command 指挥 + -er 人 → 指挥官）例：a troop commander 部队指挥官
词根 ④ -min / -minu = = 小（small / less）

钩子：min → 联想「minor 较小的」「minimum 最小的」，核心是“小”。

minute/ˈmɪnɪt/n. 分钟；/maɪˈnjuːt/ adj. 微小的（min 小 → 微小）例：a minute error 微小的错误
minimum/ˈmɪnɪməm/n./adj. 最小（值）（min 小 + -imum → 最小）例：the minimum wage 最低工资
minor/ˈmaɪnə/adj. 较小的，次要的（min 小 + -or → 较小的）例：a minor problem 小问题
minority/maɪˈnɒrəti/n. 少数，少数民族（min 小 + -or + -ity → 少数）例：a minority group 少数群体
diminish/dɪˈmɪnɪʃ/v. 减少，削弱（di- 分开 + min 小 + -ish → 变小 → 减少）例：diminish the risk 降低风险
