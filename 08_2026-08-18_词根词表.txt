-vid / -vis 看·看见
video 视频、录像
visible 可见的、明显的
visit 参观、访问
advise 建议、劝告（ad- 向 + vis → 向…看→给出看法）
evident 明显的（e- 出 + vid → 一眼看出→明显）

-press 压·按
press 压、按、催促
pressure 压力
compress 压缩（com- 共同 + press → 一起压）
depress 使沮丧、压下（de- 下 + press）
express 表达、表达出（ex- 外 + press → 压出来→流露/表达）

-gress 走·步伐
progress 进步、进展（pro- 前 + gress → 向前走）
congress 大会、国会（con- 共同 + gress → 走到一起）
aggressive 好斗的、激进的（ag- 向 + gress → 向前冲）
digress 离题（di- 分开 + gress → 走开）
regress 倒退、退化（re- 回 + gress）

-rupt 断·破
rupture 破裂、断裂
abrupt 突然的、唐突的（ab- 离开 + rupt → 断开→突然）
bankrupt 破产的（bank 钱袋 + rupt → 钱袋断了）
corrupt 腐败的、堕落的（cor- 全 + rupt → 全坏→腐败）
disrupt 扰乱、使中断（dis- 分开 + rupt → 打断）
