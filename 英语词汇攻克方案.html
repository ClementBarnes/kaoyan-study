英语词汇攻克方案

针对「基础薄弱 + 首字母顺序记不住」量身定制 · 词根组网法

制定：2026.8.4（起跑日反馈后） 方法：词根组网 + 高频优先 + 语境记忆 每日新词：约 30 个（按根分组）
为什么废弃首字母 A-Z 词表？ abandon、ability、able、about 这种排列，词与词之间没有语义联系，大脑只能硬记一串随机字母，今天记明天忘；且前 30 个里混着低频词，性价比极低。人的记忆靠网络——把同源词捆成一串，记一个根就能串起一串词。

一、三原则（背词前先记住）

① 词根词缀组网按同源词根成串记，建立语义网络，记忆效率翻几倍。
② 高频优先先攻考试最常出现的词，不碰冷门词，把有限时间砸在刀刃上。
③ 语境 + 间隔复习单词放进例句里记；按艾宾浩斯曲线反复刷，对抗遗忘。
④ 长难句先预习生词拆句前先查该句生词，否则词汇缺口会掩盖你的语法能力。

二、第一批词根组网（今日/明日可用）

每个词根配「记忆钩子」，把抽象词根和一个画面/汉字绑死，看见词根就想起意思。

词根 ① -spect / -spic  = 看（look / see）

钩子：spec → 联想「Spectator 观众（看比赛的人）」，核心就是"看"。

inspect /ɪnˈspekt/ v. 检查，视察（in- 向内 + 看 → 往里看 → 检查）
例：The manager will inspect the factory. 经理将视察工厂。
respect /rɪˈspekt/ v./n. 尊重（re- 回 + 看 → 回头看 → 看重 → 尊重）
例：We should respect the elderly. 我们应尊重老人。
expect /ɪkˈspekt/ v. 期待，预期（ex- 向外 + 看 → 向外看 → 盼望）
例：I expect a call from him. 我等他的电话。
aspect /ˈæspekt/ n. 方面，外观（a- 朝向 + 看 → 看过去的样子 → 面貌/方面）
例：This is only one aspect of the problem. 这只是问题的一个方面。
prospect /ˈprɒspekt/ n. 前景，展望（pro- 向前 + 看 → 向前看 → 前景）
例：The prospect of promotion excited him. 升职的前景令他兴奋。
perspective /pəˈspektɪv/ n. 观点，视角（per- 贯穿 + 看 → 看透 → 视角）
例：from my perspective 依我看。
词根 ② -port  = 拿 / 运 / 带（carry / bring）

钩子：port → 联想「护照 passport（带在身上的通关证件）」「机场 port（港口）」，核心是"搬运/携带"。

import /ˈɪmpɔːt/ v./n. 进口（im- 进 + 运 → 运进来 → 进口）
例：We import oil from abroad. 我们从国外进口石油。
export /ˈekspɔːt/ v./n. 出口（ex- 出 + 运 → 运出去 → 出口）
反义对照记：import 进 / export 出。
transport /trænsˈpɔːt/ v./n. 运输（trans- 跨越 + 运 → 运送）
例：Public transport is convenient. 公共交通很方便。
report /rɪˈpɔːt/ v./n. 报告（re- 回 + 带 → 带回来 → 汇报）
例：He reported the news to his boss. 他向老板汇报了消息。
support /səˈpɔːt/ v./n. 支持（sup- 在下 + 运 → 从下托住 → 支持）
例：Her family supports her decision. 家人支持她的决定。
portable /ˈpɔːtəbl/ adj. 便携的（-able 能…的 → 能带走的）
例：a portable computer 便携电脑。
词根 ③ -dict / -dic  = 说（say / speak）

钩子：dict → 联想「dictionary 字典（说话/词义的集子）」，核心是"说"。

dictate /dɪkˈteɪt/ v. 口述，命令（dict 说 + -ate 动 → 说出来 → 口述/ dictate）
例：The boss dictated a letter. 老板口述了一封信。
predict /prɪˈdɪkt/ v. 预测（pre- 前 + 说 → 预先说 → 预言）
例：Scientists predict the weather. 科学家预测天气。
contradict /ˌkɒntrəˈdɪkt/ v. 反驳，矛盾（contra- 反 + 说 → 反着说 → 反驳）
例：His words contradict the facts. 他的话与事实矛盾。
indicate /ˈɪndɪkeɪt/ v. 表明，指示（in- 朝向 + 说 → 说出来 → 指示）
例：The map indicates the way. 地图指示了路线。
dedicate /ˈdedɪkeɪt/ v. 致力于，奉献（de- 加强 + 说 → 宣示 → 献身）
例：He dedicated himself to research. 他投身研究。
词根 ④ -mit / -miss  = 送 / 派（send）

钩子：mit → 联想「missile 导弹（送出去的武器）」「admit 承认（送进来）」，核心是"送"。

admit /ədˈmɪt/ v. 承认，准许进入（ad- 朝向 + 送 → 送进来 → 接纳/承认）
例：He admitted his mistake. 他承认了错误。
commit /kəˈmɪt/ v. 犯（错），承诺（com- 共同 + 送 → 交付 → 承诺/犯）
例：commit a crime 犯罪；commit to 承诺。
permit /pəˈmɪt/ v. 允许（per- 穿过 + 送 → 放行 → 允许）
例：Smoking is not permitted here. 此处禁止吸烟。
submit /səbˈmɪt/ v. 提交，屈服（sub- 下 + 送 → 呈上去 → 提交）
例：Please submit your paper. 请提交论文。
mission /ˈmɪʃn/ n. 任务，使命（-ion 名词 → 被派出去的事）
例：a business mission 商务使命。
dismiss /dɪsˈmɪs/ v. 解雇，解散（dis- 离开 + 送 → 打发走 → 解散）
例：The case was dismissed. 案件被驳回。
词根 ⑤ -struct  = 建造（build）

钩子：struct → 联想「structure 结构（建造出来的框架）」，核心是"建造"。

structure /ˈstrʌktʃə/ n. 结构，建筑物
例：the structure of a sentence 句子结构。
construct /kənˈstrʌkt/ v. 建造，构建（con- 共同 + 建 → 搭建）
例：construct a bridge 建桥。
instruct /ɪnˈstrʌkt/ v. 指导，通知（in- 向内 + 建 → 建入脑中 → 教导）
例：The teacher instructed us. 老师指导了我们。
destroy /dɪˈstrɔɪ/ v. 摧毁（de- 否定 + 建 → 拆掉 → 摧毁）
例：The fire destroyed the building. 大火摧毁了大楼。

三、每日复习节奏（艾宾浩斯间隔）

只背不复习 = 白背。按下面节奏回刷，对抗遗忘曲线：

学习日当天操作复习触发
Day 1学新词根组（约30词），每个词读2遍+记钩子+看例句睡前过一遍
Day 2先快速复习 Day1，再学新组—
Day 4复习 Day1 词（遮住释义自测）—
Day 7复习 Day1 + Day4 之间所有词—
Day 15总复盘，标记仍不熟的词，单独加练—

工具建议：用「墨墨背单词 / 不背单词」APP 自建词库导入上述词，APP 会自动按遗忘曲线推送复习；不想用 APP，就用本方案文档 + 遮住释义自测。

四、和长难句怎么配合

正确顺序：

  1. 拿到长难句，先圈出生词，查释义、记进当天词根组；
  2. 生词解决后，再拆语法结构（找主干 → 拆修饰 → 验证翻译）；
  3. 翻译完，把句中的词根词再默背一遍，在阅读语境里巩固一次。

首日长难句卡住，本质是生词挡路，不是语法差——按这个顺序来，你会发现语法其实跟得上。

词根组网不是让你背字典，是给你一把"猜词钥匙"：考场上遇到不认识的 -spect 词，你至少能猜到它和"看"有关。先求"眼熟"，再求"精确"，弱基础阶段别苛求一次背死。
