英语词汇攻克方案

词根组网 + 生产式三机制 + 听书音频 + 不背单词自制词书

总量：01–11 批 385 词 / 74 族 12–20 批预生成待排期 重启：从 Day1 重学第 01 批

一、词汇总览

批次段词数 / 词族状态
第 01–11 批385 词 / 74 族全部保留复用，状态降级「待重学 / 待巩固」
第 12–20 批200 词 / 40 族预生成待排期（首轮 01–11 夯实后再视情况启用）
核心判断：去年词汇"偏听看、不够扎实、态度不认真"。重启不追进度，回 Day1 重学地基，用三机制把每个词打到"瞬间反应 + 会用"。

二、攻克策略 = 生产式三机制落地

① 主动回忆自测每新词日 / 复习日，本批正确率 ≥ 90% 过关（听音写词 + 遮义回想，错 ≤ 2/27）。不过关本批重测。
② 间隔复习每批启用后第 1 / 2 / 4 / 7 / 15 / 30 天回看。复习日查《复习排程表》精准定向具体批次。
③ 输出倒逼每批学完写 3–5 句 micro-writing 或用新词口述 30s，把输入变输出。

三、新词日 vs 复习日 流程

新词日（启用新批次）

  • 单词阅读环节（先听后背）：开《单词总表》点该批「▶ 联播本批」，听书过一遍（单词×2 → 词义 → 例句 → 翻译），先建立印象。
  • 词根块排版：左色条 + 词根 + 含义 + 记忆钩子；每词一行六层：🔊 + 单词 + 音标 + 词义 + 结构拆解 + 例句。
  • 附「主动回忆自测区」+「输出区」。

复习日（非新批日）

  • 每词一行四层：🔊 + 单词 + 汉译 + 例句；不配音标、不配拆解；按批次分组卡片。
  • 同样附「主动回忆自测区」+「输出区」。

四、听书音频用法

  • 音频路径 audio/<单词>.mp3（edge-tts 生成，单声道 64k）。
  • 《单词总表》每词带播放条，每批有「▶ 联播本批」按钮，可连续听一整批。
  • 通勤 / 碎片时间反复磨耳朵，配合主动回忆自测效果最佳。

五、不背单词自制词书

  • 导出文件 kaoyan_words_bbdc.txt（每行一词，导入「不背单词」APP 自制词书）。
  • 每次生成新批后由 gen_bbdc.py 同步更新，保持与单词总表一致。
