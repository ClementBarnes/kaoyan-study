词根 1 -spect / -spic = = 看（look / see）

钩子：都和"看/视野"有关：in-往里看=检查，re-再看重=尊重，ex-往外看=期待，per-透过看=视角，pro-往前看=前景

inspect/ɪnˈspekt/v. 检查，视察（in-(往里) + spect(看) → 往里看 = 检查）例：The manager will inspect the factory. 经理将视察工厂。
respect/rɪˈspekt/v./n. 尊重（re-(再/回) + spect(看) → 看重 = 尊重）例：We should respect the elderly. 我们应尊重老人。
expect/ɪkˈspekt/v. 期待，预期（ex-(出/外) + spect(看) → 往外看 = 期待）例：I expect a call from him. 我等他的电话。
aspect/ˈæspekt/n. 方面，外观（a-(朝向) + spect(看) → 看向的一面 = 方面）例：This is only one aspect of the problem. 这只是问题的一个方面。
prospect/ˈprɒspekt/n. 前景，展望（pro-(前) + spect(看) → 向前看 = 前景）例：The prospect of promotion excited him. 升职的前景令他兴奋。
perspective/pəˈspektɪv/n. 观点，视角（per-(透过) + spect(看) + -ive → 透过的看法 = 视角）例：From my perspective, it is wrong. 依我看，这是错的。
词根 2 -port = = 拿/运/带（carry）

钩子：拿/运/带：im-运入=进口，ex-运出=出口，trans-转运=运输，re-往回带=报告，sup-在下托=支持，portable 可携带

import/ˈɪmpɔːt/v./n. 进口（im-(入) + port(运) → 运入 = 进口）例：We import oil from abroad. 我们从国外进口石油。
export/ˈekspɔːt/v./n. 出口（ex-(出) + port(运) → 运出 = 出口）例：We export goods to Europe. 我们向欧洲出口商品。
transport/trænsˈpɔːt/v./n. 运输（trans-(跨) + port(运) → 转运 = 运输）例：Public transport is convenient. 公共交通很方便。
report/rɪˈpɔːt/v./n. 报告（re-(回) + port(带) → 带回 = 报告）例：He reported the news to his boss. 他向老板汇报了消息。
support/səˈpɔːt/v./n. 支持（sup-(下) + port(托) → 在下面托 = 支持）例：Her family supports her decision. 家人支持她的决定。
portable/ˈpɔːtəbl/adj. 便携的（port(带) + -able → 可带的 = 便携）例：a portable computer 便携电脑
词根 3 -dict / -dic = = 说（say / tell）

钩子：说：dict-说，pre-预先说=预言，contra-反着说=反驳，in-说进去=指，de-说下去=奉献

dictate/dɪkˈteɪt/v. 口述，命令（dict(说) + -ate → 口述 / 命令）例：The boss dictated a letter. 老板口述了一封信。
predict/prɪˈdɪkt/v. 预测（pre-(前) + dict(说) → 预先说 = 预测）例：Scientists predict the weather. 科学家预测天气。
contradict/ˌkɒntrəˈdɪkt/v. 反驳，矛盾（contra-(反) + dict(说) → 反着说 = 反驳）例：His words contradict the facts. 他的话与事实矛盾。
indicate/ˈɪndɪkeɪt/v. 表明，指示（in-(入) + dic(说) + -ate → 说进去 = 指示/表明）例：The map indicates the way. 地图指示了路线。
dedicate/ˈdedɪkeɪt/v. 致力于（de-(向下/加强) + dic(说) + -ate → 说下去(献) = 奉献/致力于）例：He dedicated himself to research. 他投身研究。
词根 4 -mit / -miss = = 送/派（send）

钩子：送/派：ad-送进=承认，com-一起送=承诺，per-送过=允许，sub-送下去=提交，mission 任务，dis-送走=解散

admit/ədˈmɪt/v. 承认，准许进入（ad-(向) + mit(送) → 送进 = 承认）例：He admitted his mistake. 他承认了错误。
commit/kəˈmɪt/v. 犯（错），承诺（com-(一起) + mit(送) → 一起送 = 承诺/犯）例：commit a crime 犯罪；commit to 承诺 犯罪；作出承诺
permit/pəˈmɪt/v. 允许（per-(通过) + mit(送) → 送过 = 允许）例：Smoking is not permitted here. 此处禁止吸烟。
submit/səbˈmɪt/v. 提交，屈服（sub-(下) + mit(送) → 送下 = 提交）例：Please submit your paper. 请提交论文。
mission/ˈmɪʃn/n. 任务，使命（miss(派) + -ion → 被派的 = 任务）例：a business mission 商务使命
dismiss/dɪsˈmɪs/v. 解雇，解散（dis-(离) + miss(送) → 送走 = 解散/解雇）例：The case was dismissed. 案件被驳回。
词根 5 -struct = = 建造（build）

钩子：建造：structure 结构，con-一起建=建造，in-建进去=指导，de-拆建=摧毁

structure/ˈstrʌktʃə/n. 结构，建筑物（struct(建) + -ure → 结构/建筑物）例：the structure of a sentence 句子结构
construct/kənˈstrʌkt/v. 建造，构建（con-(一起) + struct(建) → 一起建 = 建造）例：construct a bridge 建桥
instruct/ɪnˈstrʌkt/v. 指导，通知（in-(入) + struct(建) → 建入(灌输) = 指导）例：The teacher instructed us. 老师指导了我们。
destroy/dɪˈstrɔɪ/v. 摧毁（de-(毁) + stroy(struct变体) → 拆毁 = 摧毁）例：The fire destroyed the building. 大火摧毁了大楼。

★ 输出倒逼（强制环节）· 25 min · 用本批词写 micro-writing

学完不"用"一次，等于没学。从本批挑 至少 8 个词，写一段 80–120 字小短文（主题任意：学习/工作/生活皆可），或口述 30 秒小故事。写作日(管综)也用这些词练论证段，双重固化。

✍️ 示例框架：用 inspect / expect / aspect / support / construct / structure / contradict / perspective 写"我对重启备考的看法"——先列骨架，再成段。
提交方式：把写好的短文发回对话，我按"用词准确 + 搭配自然 + 逻辑通顺"三档反馈；或口述录音自行核对。

🅱 综合 · 数学 30 分钟（强项轻维持）

轻维持做法：
