第 07 批 20 词 · 4 组全新词根（此前未出现过）：
• -vers / -vert 转·转向：reverse 反转 / convert 转变 / divert 使分心 / version 版本 / universe 宇宙
• -form 形·形状：form 形式 / reform 改革 / transform 转变 / inform 通知 / uniform 统一的
• -clud / -clus 关·闭：include 包括 / exclude 排除 / conclude 得出结论 / exclusive 独有的
• -pend / -pens 悬挂·花费：depend 依赖 / suspend 悬挂 / expense 花费 / expensive 昂贵的 / pension 养老金
记忆钩子：记一个根，串起一串词。比如 -vers=转：re-反+verse→反转；con-共同+vert→共同转向→转化；di-分开+vert→转开→分心；uni-一+verse→转向统一→宇宙。-clud=关：in-内+clude→关进去→包括；ex-外+clude→关在外→排除；con-全+clude→全关上→结束/结论。

2. 长难句 9 · 30 min（定语从句与修饰拆解）

承接第 8 讲"先拆并列"，今天讲名词后面挂着的 that / which 从句怎么拆。阅读里一个名词常拖一长串定语，你认出"这是修饰谁的后置定语"，就能把长句切成"主干 + 挂在旁边的修饰"，分别理解。

The researcher presented a new model that explains how sleep affects memory and that challenges earlier assumptions about brain recovery.
生词预习：
• researcher /rɪˈsɜːtʃə/ n. 研究者（research + -er 人）
• presented /prɪˈzentɪd/ v. 提出、展示（present 过去式）
• model /ˈmɒdl/ n. 模型；模式
• affects /əˈfekts/ v. 影响（词根 -fect 做）
• memory /ˈmeməri/ n. 记忆（词根 -mem 记）
• challenges /ˈtʃælɪndʒɪz/ v. 挑战；质疑
• assumptions /əˈsʌmpʃənz/ n. 假设（assume 的复数）
• recovery /rɪˈkʌvəri/ n. 恢复（re-再 + cover 盖 → 重新盖上→恢复）
三步拆解：
  1. 找主干：整句核心就一句——The researcher presented a new model.（研究者提出了一个新模型）。其余全是"挂在 model 后面的修饰"。
  2. 拆并列定语：model 后面跟着 两个并列的 that 定语从句，由 and 连接：① that explains how sleep affects memory（解释睡眠如何影响记忆）；② that challenges earlier assumptions about brain recovery（挑战此前关于大脑恢复的看法）。先各拆各的，再合起来看"这个模型干了哪两件事"。
  3. 处理嵌套：从句①里还嵌了一个 how 引导的宾语从句（how sleep affects memory），这是 explain 的宾语，别和 that 定语从句搞混——that 修饰 model，how 是 explain 的内容。
💡 定语从句识别标志：名词 + that / which / who / 省略关系词。考场第一反应：看到名词后跟 that/which，先问"它修饰前面哪个名词？"把修饰从句整段"摘下来"放一边，主干立刻清爽。你能说出这句里两个 that 分别修饰谁吗？（答案：都修饰 model。）

3. 阅读精翻（工作日量）· 30 min

用你的英语二真题书，做 2022 年 Text 3（一篇，限时 + 精翻）。工作日只给 30 分钟，所以"做一篇、翻一篇、盘一篇"，讲究完成度而非数量。

Text 3 精翻流程（30 min）：
  1. 限时做（12 min）：不查词，5 道题凭理解选，标出犹豫的题。
  2. 逐句精翻（13 min）：每段逐句翻译，圈出生词归进对应词根组（今天第 07 批的词若碰到，重点记）；长难句用"先拆并列（第8讲）→ 再拆定语（第9讲）"两步法。
  3. 复盘（5 min）：对答案，统计错因（词汇 / 长难句 / 逻辑），生词补进"私人生词本"。
